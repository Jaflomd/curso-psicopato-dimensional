# PRD: Curso Psicopatología Dimensional para R1

## Meta

Formar residentes R1 de psiquiatría en formulación dimensional de casos y orientación de tratamientos por sistemas/redes transdiagnósticas, reemplazando el paradigma categórico DSM-only.

## Contexto

- Javier dicta el curso personalmente
- R1s tienen DSM-5 básico cubierto; modelos dimensionales son nuevos
- Basado en syllabus de Benning (UNLV) como punto de partida, recentrado en RDoC/HiTOP

## Parámetros

| Parámetro | Valor |
|---|---|
| Audiencia | R1 Psiquiatría |
| Sesiones | 21 (3/semana × 7 semanas) |
| Duración por sesión | 45-60 min |
| Evaluación | Caso formativo final (formulación dimensional + plan transdiagnóstico) |
| Modalidad | Presencial, dictado por Javier |

## Arquitectura del curso

### Bloque 1: Fundamentos (4 sesiones)
1. De categorías a dimensiones (p-factor, HiTOP, límites DSM)
2. RDoC (dominios, unidades de análisis, matrices, RDoC 2.0)
3. Exposoma + Staging clínico (McGorry)
4. Network Theory + Computational Psychiatry + intro PRISM

### Bloques 2-8: Por dominio RDoC/HiTOP (16 sesiones)
Cada bloque integra: modelo dimensional → psicoterapia (mecanismo + demo 10-15 min) → psicofarmacología PRISM → caso

| Bloque | Dominio | Sesiones | Terapia principal |
|---|---|---|---|
| 2 | Negative Valence / Fear | 3 | ERP + UP |
| 3 | Negative Valence / Distress | 3 | TCC/TREC + UP |
| 4 | Positive Valence / Detachment | 2 | IFS + activación conductual |
| 5 | Arousal / Regulatory | 2 | DBT skills |
| 6 | Cognitive Systems / Thought Disorder | 2 | TCC psicosis + rehab cognitiva |
| 7 | Disinhibited Externalizing | 2 | DBT + entrevista motivacional |
| 8 | Antagonistic Externalizing | 2 | IFS/psicodinámica + DBT |

### Sesión integradora final (1 sesión)
Presentación de caso con formulación dimensional completa.

## Hilos transdiagnósticos

- **Metacontrol** (Hommel): dial persistencia ↔ flexibilidad. Hogar: Sesión 15. Cruza: OCD (rigidez), impulsividad (flexibilidad excesiva).
- **Theory of Mind / Mentalización**: Hogar: Sesión 19. Cruza: psicosis (alterada), detachment (reducida), borderline (hipermentalización).

## Modelos integrados

- HiTOP (estructura jerárquica)
- RDoC (dominios y unidades de análisis)
- p-factor (Caspi)
- Network Theory (síntomas como nodos)
- Computational Psychiatry (prediction error, priors)
- PRISM (psicofarmacología dimensional)
- Exposoma (riesgo ambiental acumulativo)
- Staging clínico (McGorry)
- Metacontrol (Hommel)

## Psicoterapias incluidas

- Unified Protocol (UP)
- Exposición y Prevención de Respuesta (ERP)
- DBT Skills (distress tolerance, regulación emocional, opposite action)
- IFS / Psicodinámica (partes, mentalización)
- TCC/TREC básica (reestructuración, ABC)

## Competencia terminal

El residente formula un caso clínico real identificando:
1. Perfil dimensional (dominios RDoC afectados)
2. Ubicación HiTOP (espectros y dimensiones)
3. Factores exposómicos
4. Stage actual
5. Nodos centrales (network)
6. Plan de tratamiento transdiagnóstico (terapia + farmaco por dominio)
