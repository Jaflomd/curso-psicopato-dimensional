# Sesión 7: Tratamiento — Psicofarmacología PRISM (Fear)

## Learning Objectives

- **LO1** (Bloom 2 / Miller: Sabe): Describir el perfil PRISM del dominio Negative Valence / Fear para al menos 3 familias farmacológicas (SRI, benzodiacepinas, moduladores de glutamato), enumerando mecanismo de acción y al menos 1 limitación clínica de cada familia
- **LO2** (Bloom 4 / Miller: Sabe cómo): Comparar la indicación de psicoterapia, farmacoterapia y tratamiento combinado para al menos 3 perfiles clínicos del subfactor fear, argumentando con base en constructo RDoC, severidad y estadio
- **LO3** (Bloom 5 / Miller: Hace): Formular un plan de tratamiento integrado (modelo + terapia + farmaco) para el caso integrador del bloque, especificando diagnóstico dimensional, primera y segunda línea, y criterios de respuesta

## Take-Home Message

> Las benzodiacepinas alivian el malestar pero pueden sabotear la extinción: si el paciente no experimenta la violación de expectativa porque el fármaco amortigua la respuesta de miedo, el inhibitory learning no ocurre. Combinar bien no es sumar tratamientos — es entender qué mecanismo activa cada uno y en qué secuencia.
