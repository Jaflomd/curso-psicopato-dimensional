# Sesión 15: Arousal and Regulatory Systems

## Learning Objectives

- **LO1** (Bloom 2 / Miller: Sabe): Diferenciar arousal alto, arousal bajo y arousal inestable como perfiles transdiagnósticos, vinculando cada uno con al menos 2 presentaciones clínicas.
- **LO2** (Bloom 4 / Miller: Sabe cómo): Analizar cómo sueño, ritmo circadiano, interocepción y activación autonómica modifican atención, memoria de trabajo y control cognitivo.
- **LO3** (Bloom 5 / Miller: Demuestra): Formular un caso regulatorio-cognitivo integrando arousal, sueño, interocepción, estado afectivo y síntomas cognitivos sin reducirlo a una etiqueta diagnóstica.

## Outline (50 min)

| Min | Actividad | Notas |
|-----|-----------|-------|
| 0-5 | Recapitulación: arousal, ritmo circadiano, sueño-vigilia e interocepción | Recuperar S13-S14 y corregir mapa del bloque |
| 5-15 | Tres perfiles: arousal alto, bajo e inestable | Diferenciar ansiedad, bipolaridad, depresión, insomnio y somático-funcional |
| 15-28 | Regulación como prerrequisito cognitivo | Atención, working memory y control cognitivo dependen del estado del sistema |
| 28-40 | Caso puente regulatorio-cognitivo | Insomnio + ansiedad + distractibilidad + irritabilidad: red, no lista de diagnósticos |
| 40-48 | Discusión: qué intervención mueve primero el sistema | Sueño, TIPP/DBT, estabilización circadiana, farmacología, psicoeducación |
| 48-50 | Puente a S16 | La próxima clase entra a atención desde arousal, no desde “síntoma aislado” |

## Take-Home Message

> La cognición no flota en el vacío: atención, memoria de trabajo y control se degradan o se reorganizan según el estado de arousal y regulación del sistema.
