# Sesión 13: Red regulatoria — arousal, ritmo y estabilizadores de red

## Learning Objectives

- **LO1** (Bloom 2 / Miller: Sabe): Describir al menos 3 constructos del dominio RDoC Arousal/Regulatory Systems (arousal, ritmos circadianos, ciclo sueño-vigilia) e identificar el marcador clínico principal de cada uno
- **LO2** (Bloom 3 / Miller: Sabe cómo): Formular la manía/hipomanía como desregulación de red, integrando PVS alto, arousal elevado, sueño reducido, saliencia aumentada y menor modulación frontolímbica
- **LO3** (Bloom 4 / Miller: Sabe cómo): Comparar litio, valproato/divalproex, lamotrigina, antipsicóticos atípicos e intervenciones circadianas según el vector de red que estabilizan, sin reducirlos a "fármacos para síntomas"
- **LO4** (Bloom 5 / Miller: Sabe cómo): Analizar una viñeta bipolar/ciclotímica e identificar constructo RDoC, estadio clínico, vector de entrada terapéutico, intervención estabilizadora y RAMS prioritarios

## Outline (50 min)

| Min | Actividad | Notas |
|-----|-----------|-------|
| 0-5 | Activación: "S12 mostró el motor de recompensa; ¿qué pasa cuando el motor pierde metrónomo y freno?" | Puente explícito PVS → arousal/regulación |
| 5-12 | Red regulatoria RDoC: arousal, ritmo circadiano y sueño-vigilia como ejes que coordinan recompensa, amenaza, cognición e interocepción | Diagrama de red: PVS, NVS, arousal, frontolímbico, sueño |
| 12-22 | Manía/hipomanía como estado de red: PVS alto + arousal alto + sueño bajo + saliencia alta + freno frontolímbico bajo | No enseñar manía solo como "ánimo elevado" |
| 22-30 | Staging bipolar: pródromo, episodio agudo, recurrencia/neuroprogresión. El marcador temprano barato suele ser sueño/ritmo | Oscilador normal vs oscilador con amplitud patológica |
| 30-38 | Estabilizadores de red: litio, valproato, lamotrigina, antipsicóticos, ritmo social, DBT/TIPP. Qué vector estabiliza cada uno y qué no sobreprometer | Preview conceptual; S14 será implementación clínica completa |
| 38-46 | Ejercicio en parejas: viñeta ("ciclotimia + insomnio + PVS alto episódico + dolor/fatiga"). Mapear constructo, estadio, vector, intervención y RAMS | Facilitador sistematiza: estado → vector → estabilizador → monitoreo |
| 46-50 | Cierre: "Un estabilizador no apaga la vida emocional; reduce la varianza patológica de la red" | Puente directo a S14 tratamiento integrado |

## Take-Home Message

> La red regulatoria decide si reward se vuelve proyecto, impulsividad o manía. Los estabilizadores no apagan la vida emocional: reducen la oscilación patológica para que el sistema recupere rango, ritmo y freno.
