# Casos-Reto — Sesion 12

## Instruccion

Para cada caso, responder en 90 segundos:

1. Variable alterada principal.
2. Tecnica indicada.
3. Tecnica que NO usarias primero.
4. Primer cambio esperado.
5. RAMS principal.

---

## Caso 1 — "Cuando llega, lo disfruta"

Paciente 31 años, MDD recurrente. Dice: "Si mis amigos me sacan, la paso bien. Pero organizarme para salir me parece una montaña." Duerme 10 h, cansancio alto, no hay historia de hipomania.

**Clave docente**

| Campo | Respuesta |
|---|---|
| Variable | Effort alto + wanting bajo/moderado; liking parcialmente preservado |
| Tecnica | Activacion conductual por costo-esfuerzo |
| No primero | Insight profundo sin accion; tarea grande de socializacion |
| Cambio esperado | Baja esfuerzo anticipado; mas completions |
| RAMS | Moralizar o escalar demasiado rapido; vigilar bipolaridad aunque no haya historia clara |

---

## Caso 2 — "El cuerpo no prende"

Paciente 44 años, depresion con obesidad, dolor, sueño no reparador, CRP elevada en controles previos. "No es tristeza, es como caminar con plomo." Disfruta comida/familia cuando aparece, pero evita casi todo esfuerzo.

**Clave docente**

| Campo | Respuesta |
|---|---|
| Variable | Effort patologicamente alto + hipotesis inmune-metabolica |
| Tecnica | BA de energia limitada + ritmo/sueño/movimiento dosificado + coordinacion medica |
| No primero | Exigir ejercicio intenso o interpretar como resistencia |
| Cambio esperado | Mejor adherencia y rutina; respuesta parcial si biologia persiste |
| RAMS | Sobrecarga post-esfuerzo; ignorar base medica/metabolica |

## Caso 3 — "Quiero amigos, pero no se como entrar"

Paciente TEA, 22 años. Quiere pareja y amigos, pero queda agotado tras reuniones. Ansiedad anticipatoria intensa por no entender reglas implicitas. Ha sido ridiculizado antes.

**Clave docente**

| Campo | Respuesta |
|---|---|
| Variable | Costo de traduccion social + amenaza social aprendida |
| Tecnica | Exposicion social adaptada por canal, regla, duracion y salida |
| No primero | Exposicion social abierta sin adaptaciones; social skills como camuflaje |
| Cambio esperado | Menor costo anticipado; mas interacciones tolerables |
| RAMS | Aumentar burnout/camuflaje; invalidar trauma social |

## Caso 4 — "Todo esta encajando"

Paciente 28 años, historia de bipolaridad. Duerme 4 h sin cansancio, inicia tres proyectos, gasto alto, sexualidad impulsiva, siente que "por fin volvi a ser yo".

**Clave docente**

| Campo | Respuesta |
|---|---|
| Variable | PVS alto patologico: reward valuation alto + costo/riesgo bajo |
| Tecnica | IPSRT breve + plan de freno + red + coordinacion farmacologica |
| No primero | Activacion conductual; reforzar proyectos |
| Cambio esperado | Proteccion de sueño, menor escalada, deteccion temprana |
| RAMS | Psicosis/riesgo/insight bajo; requiere escalar cuidado si aparece peligro |

## Caso 5 — "No es tristeza, es apagamiento"

Paciente 37 años con esquizofrenia estabilizada. Pocos positivos, aislamiento, baja iniciativa, pobre rendimiento cognitivo. Tambien toma antipsicotico sedante y tiene sintomas depresivos leves.

**Clave docente**

| Campo | Respuesta |
|---|---|
| Variable | Psychosis-detachment: negativos vs secundarios por sedacion/depresion/cognicion |
| Tecnica | Separar causas + scaffolding funcional + rehabilitacion/cognicion/social |
| No primero | Asumir "negativos primarios" sin revisar medicacion/depresion/paranoia |
| Cambio esperado | Funcionamiento observable antes que placer subjetivo |
| RAMS | Suicidio post-psicotico/depresivo; desesperanza terapeutica; sobrecarga |
