## Notas para el instructor

- **K3 es nuevo en este curso:** Por primera vez se pide al R1 que *aplique* un framework para organizar información clínica (no solo que comprenda o analice un caso dado). La tarea de mini-historia por exposoma busca este salto.
- **Staging 2.0 con modificadores P+E** viene de publicaciones 2024-2026. Los R1 están recibiendo contenido de frontera.
- **La lente de salud pública** (economía, ética, comunicación, implementación) diferencia esta sesión de un enfoque puramente clínico. Staging no es solo "dónde está el paciente" sino "cómo organizamos servicios para prevenir progresión."
- **El caso de Tomás se enriqueció** con datos de exposoma específico externo (dieta, contaminación, ruido, sedentarismo) para que los R1 practiquen el mapeo en 3 dominios.
