## Card 1 — TIPSS · Carmen (inundación)

| Campo                 | Contenido                                                                                                 |
| --------------------- | --------------------------------------------------------------------------------------------------------- |
| **Paciente**          | Carmen, 29 años, ruptura reciente (3 semanas)                                                             |
| **Presente**          | Vio una historia de IG de su ex. FC ~120, temblor, nudo en garganta, urgencia de escribirle **ahora**     |
| **Conducta**          | Intentó "razonarse" 10 min en bucle; la mente en blanco; no puede nombrar emoción más allá de "explosión" |
| **Pregunta al grupo** | ¿Primera skill? ¿Por qué no ABC ahora? ¿Circuito?                                                         |

### Clave docente

|                  | Respuesta                                                                                                                      |
| ---------------- | ------------------------------------------------------------------------------------------------------------------------------ |
| **Skill**        | **TIPSS** (P respiración + S grounding; T si hay agua/frío)                                                                    |
| **Mecanismo 1B** | **High arousal**                                                                                                               |
| **RDoC**         | Sustained Threat (agudo) + Arousal/Regulatory Systems                                                                          |
| **Circuitos**    | ↑ SNS / locus coeruleus–HPA; **dlPFC offline** → TIPSS busca ↑ vagal, ↓ CeA-driven arousal, re-entrar red salience al presente |
| **Error típico** | Disputar "no debería escribirle" con arousal 9/10                                                                              |

## Card 2 — Defusión · Roberto (fusión)

| Campo | Contenido |
|---|---|
| **Paciente** | Roberto, 45 años, MDD residual (síntomas 6/9, PHQ-9 = 11) |
| **Presente** | Dice literalmente: **"Soy un fracaso total"** — no distingue pensamiento de identidad |
| **Conducta** | Dejó proyectos en el trabajo; cada mañana repite la frase como si fuera un hecho biográfico |
| **Arousal** | 4/10 — hay ventana cognitiva **limitada** por fusión, no por pánico |
| **Pregunta al grupo** | ¿Defusión, ABC o reappraisal? ¿Proceso vs contenido? ¿Circuito? |

### Clave docente

| | Respuesta |
|---|---|
| **Skill** | **Defusión cognitiva** (luego ABC si hace falta cuestionar contenido) |
| **Mecanismo 1B** | **Impaired disengagement** + narrativa pegada |
| **RDoC** | Cognitive control (meta-representación) |
| **Circuitos** | Captura WM por narrativa self-referential (**DMN** mPFC/PCC); defusión = distancia meta-representacional antes de **goal updating** dlPFC |
| **Error típico** | Reestructuración prematura ("mira tus logros") sin des-fusión → refuerza debate de contenido |

## Card 3 — Exposición al malestar · Elena (evitación experiencial)

| Campo | Contenido |
|---|---|
| **Paciente** | Elena, 52 años, duelo por hijo (8 meses) |
| **Presente** | No entra al cuarto del hijo; predice: "Me deshago, no paro de llorar, no podré trabajar" |
| **Conducta** | Anestesia entre semana; llanto solo cuando "se escapa"; evita fotos y ropa |
| **Arousal** | 5/10 al nombrar el cuarto — evitación conductual + emocional |
| **Pregunta al grupo** | ¿Exposición, TIPSS o ABC? ¿Qué PE testeamos? ¿Circuito? |

### Clave docente

| | Respuesta |
|---|---|
| **Skill** | **Exposición al malestar** (titulada: 5 min puerta abierta o 2 min foto — con predicción previa) |
| **Mecanismo 1B** | ↓ reward expectation / **evitación de PE adaptativo** sobre tolerabilidad |
| **RDoC** | **Loss** (+ yearning / NAcc si se discute) |
| **Circuitos** | **Ínsula** interoceptiva + **vmPFC** (integración "ola tolerable"); evitación mantiene predicción de castigo corporal sin actualización |
| **Error típico** | ABC sin exposición → nunca testea "puedo sentir y no colapsar" |

## Card 4 — ABC · Diego (representación en B — core)

| Campo | Contenido |
|---|---|
| **Paciente** | Diego, 34 años, distress con **IU** dominante |
| **A** | Pareja sin responder WhatsApp (3 h) |
| **B** | "Le pasó algo grave y es mi culpa por no estar pendiente" |
| **C** | 40+ mensajes de chequeo + rumiación 2 h |
| **Arousal** | 6/10 — ventana cognitiva **suficiente** tras breve regulación |
| **Pregunta al grupo** | ¿Por qué disputamos **B** y no **A**? ¿Goal updating? ¿Motor? ¿Circuito? |

### Clave docente

| | Respuesta |
|---|---|
| **Skill** | **ABC** (disputa B + **disputa de proceso** IU: "debo saber ya") |
| **Mecanismo 1B** | Representación rígida en WM / mood-congruent bias |
| **RDoC** | Cognitive control — **goal updating** |
| **Circuitos** | **dlPFC–ACC** actualizan evaluación; **hippocampo** recupera episodios alternativos; PE sobre expectativa de catástrofe |
| **Error típico** | Quitar el teléfono (modificar A) sin tocar B |

## Card 5 — Reappraisal UP · Lucía (ventana + tiempo real)

| Campo | Contenido |
|---|---|
| **Paciente** | Lucía, 26 años, episodio de tristeza en **sesión** (no crisis) |
| **Presente** | Tras hablar de un rechazo laboral: tristeza 6/10, pensamiento automático **"esto confirma que nunca voy a salir adelante"** |
| **Contexto** | Ya hizo 3 min respiración; arousal estable |
| **Pregunta al grupo** | ¿Reappraisal UP vs ABC retrospectivo? ¿Mismo circuito que disputa B? |

### Clave docente

| | Respuesta |
|---|---|
| **Skill** | **Reappraisal UP** (emoción → pensamiento → 1 reappraisal temporal o de evidencia) |
| **Mecanismo 1B** | Representación en WM — actualización **online** |
| **RDoC** | Cognitive control aplicado a Negative Valence |
| **Circuitos** | **dlPFC** modula **amígdala** (Ochsner & Gross); misma familia que goal updating, timing en vivo |
| **Error típico** | Positividad tóxica; reappraisal sin identificar emoción primero |
